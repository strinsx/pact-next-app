You are redesigning an existing web application into a premium Dark Mode experience.

## Design Philosophy

The application should feel like Linear, Raycast, Arc Browser, and Notion had a child—but with a friendlier personality suitable for an accountability platform.

The design must NOT look cyberpunk, gaming, or AMOLED black.

Instead, it should feel:

• Calm
• Trustworthy
• Focused
• Modern
• Soft
• Productive
• Premium SaaS

Think:
- Accountability
- Progress
- Community
- Consistency
- Encouragement

Every screen should feel comfortable enough to use for hours.

## Gradient Language

The application's signature gradient is:

Lavender → Sky Blue → Mint

Use gradients sparingly for:

- Hero sections
- Analytics numbers
- Premium badges
- Progress rings
- Feature highlights

Never use gradients as page backgrounds.

↓

Cards

↓

Floating Cards

↓

Every layer should become slightly lighter than the previous.

---

## Borders

Every card must have:

- subtle border
- soft elevation
- rounded corners

Avoid hard separators.

Use borders instead of heavy shadows whenever possible.

---

## Shadows

Use soft shadows only.

Never create floating neon effects.

The UI should feel elevated but lightweight.

## Overall Feeling

The application should feel like:

"I trust this app."

instead of

"This app is trying to impress me."

Design priorities:

1. Readability
2. Calmness
3. Consistency
4. Spacious layouts
5. Accessibility
6. Premium but understated

Avoid:

- Pure black
- Neon colors
- Glassmorphism
- Excessive blur
- Loud gradients
- Oversaturated buttons
- Heavy shadows
- High contrast everywhere

Aim for a modern, premium productivity platform where users feel encouraged to return every day and stay focused on their commitments.
